# MedBot — Autonomous Hospital Delivery Robot

Simulated autonomous hospital delivery robot translating natural language instructions into structured navigation missions using DistilBERT intent classification, A* path planning, and Webots robotics simulation.

## Tech Stack
- Python
- DistilBERT
- Webots
- Whisper
- A* Navigation
