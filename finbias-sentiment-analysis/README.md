# FinBias — Financial Sentiment Analysis Engine

NLP sentiment analysis comparing TF-IDF baselines with fine-tuned FinBERT models for financial news and market earnings reports.

## Tech Stack
- FinBERT
- Transformers
- PyTorch
- scikit-learn
- Python
