## Suggested website sections for the next phase

1. **Introduction:** name, confirmed headline, a short introduction, and a link to projects.
2. **Featured work:** the six selected projects, each with a real screenshot and a concise description.
3. **Skills:** group technologies demonstrated in the selected work instead of using percentage skill bars.
4. **About:** your own background, interests, and contribution to these projects.
5. **Contact:** your preferred email, GitHub, LinkedIn, and optional resume.

A case study should explain the problem, your role, the architecture, a key technical decision, the evidence, and the remaining limitations. Link to a repository or demo only when an actual shareable destination exists.
